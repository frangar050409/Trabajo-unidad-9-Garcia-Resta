    🔍 Auditoría del Torneo Algorítmico

    ¿Por qué el || no frenaba el torneo?

    Con victoriasUsuario < 3 || victoriasMaquina < 3 alcanza con que uno de los dos tenga menos de 3 para que la condición sea true. Cuando el usuario llega a 3, la máquina todavía tiene menos de 3, así que el bucle sigue: solo se detendría si los dos llegaran a 3 a la vez, algo que nunca pasa.

    ¿Qué línea hace que el bucle devuelva false?

    while (victoriasUsuario < 3 && victoriasMaquina < 3), junto con los acumuladores victoriasUsuario++ y victoriasMaquina++. Cada ronda ganada suma 1; cuando cualquiera llega a 3, una de las dos partes es false y con && el bucle se corta.
